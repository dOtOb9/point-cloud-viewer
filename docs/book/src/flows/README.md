# 処理の流れ（入口つき）

この章は、リファクタリングのときの地図です。**処理ごとに「何をしているか」と「最初に呼ばれるファイルと関数」**を
書いています。各ページは同じ形です。

1. 何をするか
2. **入口**（最初に呼ばれる `src/...` の関数）
3. **流れ**（順番に呼ばれる関数。番号つき）
4. 状態の持ち場所（どの hook が何を持つか）
5. 関連する ADR・タスクシート、落とし穴

ファイル名・関数名は、書いた時点で `grep` して実在を確かめたものです。名前が変わっていたら、
そのページの名前でリポジトリ全体を検索すると、移動先が見つかります。

| ページ | 内容 |
|---|---|
| [起動](./startup.md) | `main.tsx` からビューアが動くまで |
| [ファイルを開く](./open-file.md) | 「開く」・D&D から、レイヤーが画面に出るまで |
| [毎フレームの描画](./render-frame.md) | `renderOnce` の中身 |
| [レイヤー操作](./layers.md) | 表示・選択・着色・移動・削除 |
| [計測](./measure.md) | 計測ボタンから計測レイヤーまで |
| [エラーの流れ](./errors.md) | どこで受け止められ、どこに出るか |
| [設定と単位](./settings.md) | 設定の一覧、保存先、単位の換算 |

状態を持つ場所（hook）の全体は [src/state](../frontend/state.md)、画面の部品は [src/ui](../frontend/ui-shell.md)、
レンダラは [src/renderer](../frontend/renderer.md) に書いてあります。
