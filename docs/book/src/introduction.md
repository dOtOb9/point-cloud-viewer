# はじめに

## この本は何か

これは `point-cloud-viewer` の**コードを読む前に読む本**です。ADR（設計判断の記録。
[用語集](./glossary.md)参照）やタスクシートの書き写しではありません。

このリポジトリには、判断の経緯を記録した `TaskSheets/ADR-0001`〜`ADR-0013` と、
作業記録である `TaskSheets/M0`〜`M4` のタスクシートがすでにあります。**なぜその設計に
なったか**を知りたいときは、今もそれらが一次資料です。この本は、そこへ行く前に
**全体像をつかみ、どのファイルから読めばいいかを示す地図**です。

## 読み方

各章は次の3つを短く書きます。

- **このコードは何をしていて、なぜそうなっているか**
- **経緯**（ADR へのリンク。詳しい判断の理由はそちらにあります）
- **節ごとのソースファイルへのリンク**。GitHub 上のファイルを直接開けます

各章の最後に「**まず読むファイル**」を1〜3個挙げます。迷ったらそこから読んでください。

## 正確さについて

この本の内容は、ADR やタスクシートではなく**実際のコード**を確認して書いています。
両者が食い違っている箇所（例: 変換は当初デスクトップだけの機能として設計されましたが、
その後 Android と Web でも行うようになりました）は、**コードの通りに**書いています。

画面や実機で確認されていないことは「未確認」と明記します。本の内容を鵜呑みにせず、
疑わしい箇所はリンク先のソースファイルを実際に開いて確認してください。

## 手元で開く

標準の mdBook だけでビルドできます（拡張は使っていません）。

```bash
cargo install mdbook   # 入っていなければ
mdbook serve docs/book
```

ブラウザで `http://localhost:3000` を開くと、保存するたびに再読み込みされます。
一度だけビルドしたい場合は `mdbook build docs/book`（`docs/book/book` に出力されます）。
