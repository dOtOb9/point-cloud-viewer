# 1枚の図で見る

[処理の流れ](../flows/README.md) の章は、手順を上から順に文章で追います。
この章は逆に、**1つの操作に関わるものを1枚の図に並べて**、全体を見渡すためのものです。

それぞれの図は次の3つに答えます。

1. **値はどこで生まれるか** — React の state・ref・設定。どのフックが持ち主か
2. **どこで束ねられ、誰が呼ぶか** — ボタンなどの UI から `src/app/` の関数に入るまで
3. **結果はどこへ戻るか** — setter で React の state に入り、再描画でどの部品が表示するか

細かい分岐や理由は図に書きません。それぞれの図から、対応する「処理の流れ」の章へ飛んでください。
