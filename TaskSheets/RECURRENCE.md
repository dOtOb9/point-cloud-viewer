# 再発防止の台帳

`AGENTS.md` の「承認の後の再発防止策」で、タスクごとに作業エージェントが書き、監査役が承認する。
1タスク1節。指摘ごとに「根本原因」と「次から防ぐ仕組み」（人の注意に頼らない物を優先）を書く。

形式:

```
## <タスクID>（<日付>、監査: R<n> で APPROVE、再発防止: <APPROVE の日付>）

| 指摘 | 重さ | 根本原因 | 防ぐ仕組み（種類: テスト / lint / CI / スクリプト / 決まり / 注意） | 置いた場所・コミット |
|---|---|---|---|---|
```
